# SprachKasse - German for Retail

🔗 Live demo: https://lukas-56376.github.io/Sprachkasse/

## What is this?

**SprachKasse** is an interactive learning web app that helps Polish-speaking users learn **German for retail work**. The app guides learners step by step from **A2 to B1** through practical, job-related situations from everyday retail and customer interaction (e.g. greeting customers in a store, customer conversations, typical checkout/retail vocabulary).

The content is specifically tailored for **German–Polish** learners: hints and translation help are offered bilingually to make getting started easier.

## Features

- **📊 Dashboard**
  An overview of learning progress right at the start: current level, total XP, daily streak, and daily goal (e.g. 0/50 XP), plus a direct entry point into the next upcoming lesson.

- **📚 Learning path ("Lernen")**
  A structured, numbered lesson path (e.g. "01 – Greeting Customers in a Store") that progresses step by step from A2 to B1. Each lesson is tagged with a topic area (e.g. "Customer contact").

- **📝 Lessons with hints**
  Individual exercises offer tiered hints:
  - Hint 1 – in German
  - Hint 2 – in Polish (Polski)
  - Hint 3 – the solution
  Answers can be checked directly at the end of each exercise.

- **🔤 Words (vocabulary trainer)**
  A collection of key retail terminology, with a search function to look up specific words.

- **📈 Progress**
  A detailed statistics view showing:
  - Total XP
  - Number of completed lessons
  - Number of words learned
  - Current language level
  - Streak (consecutive days learning)
  - Daily goal progress

- **👤 Profile**
  A personal area with a savable name plus a summary of level, XP, streak, and completed lessons.

- **📱 Navigation**
  A clean navigation bar (Home, Learn, Words, Profile) for quickly switching between sections — responsive and optimized for mobile devices (viewport-fit: cover).

## Target audience

Native Polish speakers who work (or want to work) in German-speaking retail and want to build up their job-related German skills from A2 to B1.

## Technical notes

The app runs as a static website hosted on **GitHub Pages** and works directly in the browser — no installation required.
